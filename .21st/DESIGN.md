# Remex design context

- React + Vite. Main tokens live in `src/style.css`.
- Warm ivory (`--paper`), dark ink (`--ink`), and a restrained orange accent.
- Service-first, editorial layout: clear headings, grid lines, flat panels, modest corners.
- Reuse `LineButton`, `Header`, `Footer`, and the bilingual `text()` helper.
- Keep Japanese and English routes, prices, filming permission requirements, service availability, and legal terms consistent.
- Illustrations must be labeled as fictional; there are currently no public sample videos or customer testimonials.
- Avoid decorative slogans, English eyebrows, glass, and motion outside the hero.
- User-selected hero motion: real Tokyo footage changes approximately every 6 seconds with a 0.8-second crossfade. Text stays still. Reduced motion uses a static poster; user pause and offscreen/hidden-tab pause stop both playback and cycling.
- The current two scenes are temporal excerpts of one verified stock source, not different locations.
- 21st catalog search was attempted during this refresh but requires sign-in. No catalog code or dependencies were added.
